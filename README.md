# Predictive-Cardiovascular-Risk-Analytics-System
Comprehensive clinical decision support system utilizing Python, MICE imputation, Logistic Regression, Random Forest, and XGBoost on 920 UCI heart disease records. Features a 3-tier risk triage engine ($&lt;35\%$, $35\text{--}70\%$, $>70\%$) prioritizing recall ($90.2\%$) to minimize false negatives and reduce redundant diagnostic screenings.
